# Venworks Canvas and UI Data Layer

## Version 1.0.0 (UNRELEASED)

- Requires Venworks Core Library 2.1.8 or higher.
- Adds support for multiple compatible HUD add-ons to display their panels together in the Player HUD.
- Includes optional Example and Component Gallery panels for testing and demonstration.
- Disables Watch display and alert animations while keeping the underlying data available.
- Keeps consumer load requests retryable while a new HUD activation is pending and discards obsolete requests that were never submitted.
- Restores separate, per-plugin Spriggit dump and assembly commands and keeps fresh-checkout staging preparation under maintainer control.
- Preserves unselected build outputs and checks installed packages against their recorded inputs, with isolated packaging transactions and verified recovery copies.
